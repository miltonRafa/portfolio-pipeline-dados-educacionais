O que é o Power BI?

Neste artigo

O Power BI é a plataforma de análise de negócios da Microsoft que ajuda você a transformar dados em insights acionáveis. Seja você um usuário de negócios, criador de relatórios ou desenvolvedor, o Power BI oferece ferramentas e serviços integrados para se conectar, visualizar e compartilhar dados em toda a sua organização.

O Power BI é um componente principal do Microsoft Fabric, fornecendo recursos de análise e visualização. Em Fabric, Power BI compartilha recursos como integração de dados, fluxos de dados (herdados) e segurança com outras experiências Fabric. No entanto, alguns recursos - como relatórios do Power BI, dashboards e o serviço do Power BI - são exclusivos do Power BI.

Power BI e Microsoft Fabric

O Microsoft Fabric é uma plataforma de análise all-in-one que inclui o Power BI como uma de suas principais cargas de trabalho. Se você for um usuário do Power BI, veja o que precisa saber.

Pontos principais:

  • Nenhuma migração necessária – seu conteúdo e workspaces do Power BI permanecem os mesmos.
  • Use sua conta existente do Power BI ou do Microsoft 365 para entrar.
  • O Fabric adiciona novos recursos, mas a interface e a experiência do Power BI permanecem familiares.

Passo a passo do Power BI

Início rápido: Inscreva-se no Power BI | Baixar o Power BI Desktop | Acesse o serviço Power BI

Siga estas etapas para começar a usar o Power BI:

  1. Introdução: inscreva-se e configure seu workspace. Baixe o Power BI Desktop ou use o serviço do Power BI em seu navegador.
  2. Conectar e preparar dados: conecte-se a fontes como Excel, SQL ou serviços de nuvem. Limpe e modele seus dados.
  3. Modele e combine dados: crie relações, adicione cálculos e combine fontes para uma exibição completa.
  4. Criar relatórios e painéis: use ferramentas de arrastar e soltar para criar visuais interativos.
  5. Explore e analise: Filtrar, classificar e fazer drill down para encontrar insights. Use uma análise integrada.
  6. Compartilhar e colaborar: Publique no serviço do Power BI, compartilhe com sua equipe e colabore em tempo real.
  7. Administrar e proteger: gerenciar o acesso, configurar funções de segurança e monitorar o uso.

Para obter um detalhamento dos recursos de serviço do Power BI organizados pela função de usuário (criadores versus consumidores), consulte Noções básicas do serviço do Power BI.

Power BI Desktop versus o serviço do Power BI

O Power BI tem dois componentes principais: o Power BI Desktop e o serviço do Power BI. O aplicativo de desktop é melhor para modelagem de dados e criação de relatórios, enquanto o serviço é ideal para compartilhamento e colaboração. Ambos podem se conectar a fontes de dados e criar visualizações. Há também um aplicativo do Power BI Mobile para exibir relatórios em qualquer lugar.

Principais recursos do Power BI Desktop e do serviço do Power BI

O Power BI Desktop e o serviço do Power BI têm recursos exclusivos que atendem a diferentes aspectos da análise de dados e relatórios.

Power BI Desktop:

  • Conecte-se a mais de 100 fontes de dados, incluindo bancos de dados, serviços de nuvem, arquivos e fontes da Web
  • Usar o Editor do Power Query para transformação de dados
  • Criar modelos de dados com DAX, colunas calculadas e relações
  • Acessar mais de 30 visuais internos e personalizados
  • Utilizar recursos avançados, como analisador de desempenho, ferramentas externas e modelos compostos
  • Introdução ao Power BI Desktop

Serviço do Power BI:

  • Usar workspaces para colaboração em equipe
  • Criar aplicativos para distribuir dashboards e relatórios
  • Criar fluxos de dados para preparação de dados reutilizável
  • Compartilhar conjuntos de dados em relatórios
  • Criar painéis em tempo real e dados de streaming
  • Agendar atualização, configurar assinaturas de email, criar alertas, usar Q&A, inserir conteúdo e exportar dados
  • Implementar a segurança com RLS, rótulos de confidencialidade, métricas de uso e logs de auditoria
  • Saiba mais sobre o serviço do Power BI

Funcionalidades e recursos especializados do Power BI

O ecossistema do Power BI inclui ferramentas e recursos especializados para aprimorar relatórios e análises.

  • Relatórios paginados: use esses relatórios para relatórios estruturados e imprimíveis, como faturas. Crie-os usando o Construtor de Relatórios do Power BI. Saiba mais sobre relatórios paginados.
  • Relatórios locais: usando o Servidor de Relatórios do Power BI, você pode manter relatórios locais, com a opção de migrar para a nuvem mais tarde. Saiba mais sobre o Servidor de Relatórios do Power BI.
